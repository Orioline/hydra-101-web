# Hydra数游戏

基于数学中的Hydra数概念开发的Web小游戏，展示了无限增长和复杂分裂的数学现象。

## 需求背景

** 以下内容为用户原始需求 **

当前我希望编写一个Web小游戏页面。

该游戏背景为数学中的Hydra数，游戏玩法如下：
- 一开始，游戏中有一条N头蛇，默认为4头蛇，蛇的初始HP=2。
- 玩家攻击这条蛇时，蛇每降低1HP会掉下1枚鳞片，直至蛇的HP降为0。
- N头蛇死亡时，掉落的每片鳞片都会变为一条(N-1)头蛇，换言之，蛇的HP上限是多少，被击杀后就会分裂成多少条小蛇，1头蛇被击杀时不会分裂出更小的蛇。
- 但每当玩家攻击蛇导致蛇死亡时，当前蛇的HP是多少，其它所有蛇（包括未来新诞生的蛇）的HP上限会增加多少。
  - 该设计可控制所有蛇的生命增长率为2的整数幂。
- 玩家每次专注攻击当前的蛇，当前蛇死亡时，选择下一条当前头数最少的蛇进行攻击。
- 由于玩家会有序攻击所有蛇，因此可以使用计数方案分类记录剩下的各类蛇的数量，除当前正在攻击的蛇外，无需为其它剩余蛇创建对象，以节约资源使用。
- 游戏界面使用左右布局，左侧为玩家，右侧为当前正在攻击的蛇和剩余的蛇群。界面中可以使用文字显示战况。
- 由于游戏中可能出现极大数字，因此所有数字展示时需使用封装函数，以便使用科学计数法甚至特殊表示法。
- 玩家可以切换武器，不同武器代表不同“增长率”。但无论使用何种武器，都需保证蛇的HP增长率及分裂规则不变。
  - 剑：直接对蛇造成伤害，蛇每受到x点伤害掉落x片鳞片。
  - 锤：攻击1头蛇时，秒杀y头1头蛇，其它蛇HP翻2^y倍；攻击非1头蛇时，秒杀当前蛇。
- 玩家可以对武器升级，每升级一次武器，当前武器的伤害增长一个级别。

## 游戏规则

### 基本规则
1. **初始状态**：游戏开始时有一条N头蛇（默认N=4），HP=2
2. **攻击机制**：
   - 攻击当前蛇，使其HP减少并掉落鳞片
   - 蛇HP降为0时死亡
   - 1头蛇死亡不分裂
3. **分裂规则**：N头蛇死亡时，产生"掉落鳞片数量"的(N-1)头蛇
4. **全局影响**：每次攻击导致HP-1时，所有蛇（包括未来新生蛇）的HP上限+1
5. **攻击顺序**：当前蛇死亡后，选择头数最少的蛇攻击
6. **胜利条件**：所有蛇死亡时游戏胜利

### 攻击流程
1. 掉落鳞片（当前蛇HP-1，鳞片+1）
2. 判定蛇是否死亡（如果HP≤0）
   - 如果死亡：处理分裂规则
   - 选择下一条蛇（头数最少的）
3. 增加所有蛇的HP上限

## 数学背景

### Hydra数
Hydra数（也称为Goodstein序列）是数论中的一个概念，展示了即使从很小的数字开始，通过特定规则操作，数字可以增长到难以想象的大小。

### 游戏中的数学
- 每次攻击增加所有蛇的HP上限，导致指数级增长
- 蛇的分裂规则产生组合爆炸
- 游戏展示了无限增长的可能性
